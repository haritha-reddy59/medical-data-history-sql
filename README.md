# Medical Data History Analysis Using SQL

## Project Overview
This project focuses on analyzing medical data using SQL to explore patient information, hospital admissions, doctor details, and province data. The project demonstrates how SQL queries can be used to retrieve, filter, group, and analyze structured datasets.

## Tools Used
- MySQL Workbench
- SQL

## Database Tables
- `patients`
- `admissions`
- `doctors`
- `province_names`

## SQL Concepts Covered
- SELECT, WHERE, and ORDER BY
- DISTINCT and filtering
- Aggregate functions such as COUNT, SUM, MIN, and MAX
- GROUP BY and HAVING
- INNER JOIN
- UNION ALL
- String and date functions
- CASE expressions
- Calculated fields

## Key Learning Outcomes
- Retrieve and filter records using SQL conditions.
- Summarize data using aggregate functions and grouping.
- Combine related tables using joins.
- Apply string, date, and conditional functions to solve analytical questions.

## Project Files
- `medical_data_history.sql` — SQL query examples used for analysis.

## Note
This repository is intended for educational and portfolio purposes. Database credentials and private patient information are not included.
